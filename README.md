# BridgeGlobale

This is my project for the Alphirix internship (BuildCamp 2026) — a landing page for BridgeGlobale, a marketplace idea that helps Ghanaian vendors sell their products to customers globally. My job was to build the frontend and get people to join a waitlist.

## Built with
- React (Vite)
- Tailwind CSS
- React Router
- Formspree for the waitlist form
- Hosted on Vercel

## What's on the site
- A navbar with 3 pages (Home, Vendors, About)
- A hero section with a rotating image carousel
- Features and How It Works sections
- A product grid with working category filters and hover effects
- A waitlist form that actually sends real submissions

This was my first real project using React. Started out not really knowing what `.map()` or `useState` even did, and by the end I was building a working product filter and a multi-page site from scratch. Still learning, but proud of how far this came in a few days.
